# 外掛安全邊界

## 能提供的隔離

- 私有實現以獨立二進位制交付，宿主公開原始碼不包含其業務邏輯。
- 程序協議避免 Go 動態連結和共享記憶體 ABI。
- 包簽名和檔案雜湊防止未授權替換。
- UI 使用短時 URL、獨立 Bridge Token 和 sandbox iframe。
- 外掛故障時 OAuth 外掛路徑失敗關閉，不靜默切回另一種網路行為。

## 不能提供的保證

- 閉源二進位制仍可能被逆向分析。
- 子程序不是作業系統沙箱。
- 外掛擁有 Sub2API 服務使用者可訪問的檔案、環境變數和網路許可權。
- 包簽名證明發布者身份，不證明實現無漏洞或符合 Provider 條款。

## 部署要求

- 官方 OpenAI Transport 使用宿主內建公鑰；只向 `plugins.trusted_publishers` 新增經過稽核的第三方公鑰。
- 使用專用低許可權系統使用者執行 Sub2API。
- 限制該使用者的檔案許可權、出站網路和環境變數。
- 不向外掛環境注入無關金鑰。
- 對外掛升級保留舊包和回滾流程。
- 記錄安裝、啟用、停用、配置和刪除操作，但不記錄配置明文。

## 敏感資料

外掛處理真實 OAuth Authorization 請求頭，必須避免將請求頭、請求體、代理憑據和上游敏感響應寫入日誌或診斷訊息。UI 配置中不應出現 OAuth Token。
